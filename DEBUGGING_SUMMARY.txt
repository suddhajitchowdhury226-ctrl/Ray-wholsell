ISSUE: /api/orders/checkout returning 500 errors

ROOT CAUSE IDENTIFIED: ✅ CONFIRMED

When users try to checkout, the system cannot populate products from the cart,
resulting in empty order items, which causes validation to fail.

WHY THIS HAPPENED
───────────────────────────────────────────────────────────────────────────────

Most likely cause: Product Import/Migration

Evidence:
  • Old product IDs all start with "6a81c579" (consistent pattern)
  • New product IDs start with "6a8dc..." (different pattern)
  • This suggests products were re-imported or migrated
  • Old cart references weren't updated during migration
  • Products were deleted but carts were left behind

Prevention strategies:
  1. Always update cart references when importing products
  2. Use database transactions for bulk operations
  3. Test cart checkout after any product data changes
  4. Monitor for orphaned references regularly
  5. Implement cascade deletes on product deletion

QUESTIONS ANSWERED
───────────────────────────────────────────────────────────────────────────────

Q: Why is checkout returning 500 errors?
A: Cart items reference products that don't exist in the database. When
   checkout tries to populate products, it gets NULL values and the order
   creation fails.

Q: Is there a bug in the checkout code?
A: No. The code is correct. The issue is purely data-related (orphaned
   product references in carts).

Q: How many items are affected?
A: 10 items across 5 carts are orphaned. All must be removed or remapped.

Q: Will checkout work after running fix-orphaned-carts.js?
A: Yes. Once orphaned items are removed, checkout will work normally for
   new orders with valid products.

Q: Do users lose their carts?
A: Yes, if you run fix-orphaned-carts.js. Users will need to re-add items.
   However, you can implement Option 2 to preserve carts with product mapping.

Q: How can this be prevented in the future?
A: Implement cascade delete for products, add referential integrity checks,
   and test checkout after any product data modifications.
